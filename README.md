# ☁️ 클라우드 아키텍트 퀘스트 (cloud-quest)

신입 클라우드 아키텍트가 되어 고객 프로젝트를 하나씩 해결하며 **AWS 아키텍처**를 익히는 학습 게임입니다.
**AWS Certified Solutions Architect – Associate (SAA-C03)** 준비를 목표로 만들었고, 아이폰 홈 화면에 추가해 앱처럼 쓰도록 설계했습니다.

▶ **플레이:** https://ackerman-3.github.io/cloud-quest/

---

## 주요 기능

### 프로젝트 진행
한 프로젝트는 아래 순서로 진행됩니다.

1. **프로젝트 배정·고객 미팅**: 픽셀 아트 캐릭터와의 대화로 요구 사항을 파악합니다.
2. **솔루션 검토(퀴즈)**: SAA-C03 출제 방식(요구 사항 → 가장 알맞은·비용 효율적인·운영 부담이 적은 방법)을 따른 객관식 문제입니다. 틀리면 해설을 보여 줍니다.
3. **설계·시뮬레이션**: AWS 서비스를 구성도에 배치하고 연결한 뒤, 장애·트래픽 급증·보안 공격 같은 시나리오로 설계를 검증합니다.
4. **마무리**: 결과 화면에서 별점과 보상을 받습니다.

### 구성도 설계실
- 서비스 카드를 끌어다 놓거나, 누른 뒤 영역을 눌러 배치합니다. 배치 범위(서브넷·VPC 경계·리전 등)가 맞지 않으면 이유를 안내합니다.
- AWS 공식 아키텍처 아이콘을 쓰고, 연결선은 AWS 구성도처럼 꺾은선으로 그립니다.
- 배치한 아이콘이나 연결선을 누르면 **×** 버튼이 떠서 바로 지울 수 있습니다.
- **정답 보기**: 정답 구성과 해설, 내 설계와의 비교를 보여 줍니다.
- **틀린 곳 보기**: 내 구성도 위에 정답과 다른 배치·연결을 빨간색으로, 빠진 서비스·연결을 빨간 점선으로 표시합니다.

### 난이도와 승급
| 직급 | 난이도 | 프로젝트 수 | 열리는 조건 |
|---|---|---|---|
| 신입 아키텍트 | 쉬움 | 12 | 처음부터 |
| 주니어 아키텍트 | 보통 | 13 | 쉬움 3개 완료 |
| 시니어 아키텍트 | 어려움 | 11 | 보통 3개 완료 |

VPC·서브넷 기초부터 Multi-AZ, Auto Scaling, 서버리스, 메시지 큐, 하이브리드 연결, 재해 복구, 보안 서비스까지 다룹니다.

### 학습·복습
- **학습 탭**: 프로젝트 전에 읽는 개념 노트 11개(구성도 읽는 법 포함)를 제공합니다. 프로젝트 카드의 **개념보기**로 바로 열 수 있습니다.
- **다시 하기**: 한 번 완료한 프로젝트는 퀴즈만 또는 구성도만 다시 풀 수 있습니다(보상은 전체 수행보다 적음).
- **기록 탭**: 학습 달력, 연속 학습일, 최근 완료 내역을 보여 줍니다.
- **계정(선택)**: 초대 코드로 가입하면 아이디·비밀번호로 로그인하고 기록을 서버(Supabase)에 저장해 여러 기기에서 이어서 할 수 있습니다. 설정 방법은 [SERVER-SETUP.md](SERVER-SETUP.md).

### 보상
- 프로젝트 완료·복습·출석으로 골드를 받습니다. 같은 날 같은 프로젝트를 반복하면 보상이 없습니다.
- 별점은 3개에서 시작해 해설을 보거나 시뮬레이션을 4회 이상 돌리면 줄어듭니다.

### 사무실
- 남산이 보이는 아이소메트릭 픽셀 사무실에서 동료(케이 팀장, 변의주 선배, 니콜라스 동기)를 눌러 **이야기하기**, **간식 나누기**를 하며 **팀워크**를 쌓습니다. 함께한 프로젝트를 완료해도 팀워크가 오릅니다.
- 팀워크 단계(첫 인사 → 익숙한 동료 → 믿음직한 동료 → 최고의 파트너)에 따라 동료 에피소드, 사무실 소품, 팀 사진이 열립니다.
- 골드로 가구(화분, 조명, 커피 코너, 러그, 선반, 라운지 소품)를 사서 지정된 자리에 배치하고, 성과로 받은 기념품을 선반에 전시합니다.

## 기술 구성

| 항목 | 내용 |
|---|---|
| 프레임워크 | Vite + React + TypeScript |
| 서버 | 선택: Supabase(계정·기록 동기화). 설정하지 않으면 순수 정적 웹앱 |
| 저장 | 기기 브라우저 localStorage (백업 파일 내려받기·복원 지원), 로그인 시 서버에도 저장 |
| 배포 | GitHub Actions → GitHub Pages |
| 업데이트 | 앱을 열거나 다시 띄울 때 `version.json`을 확인해 새 버전이면 자동 새로고침 |

## 로컬에서 실행

```bash
npm ci
npm run dev        # 개발 서버
npm run build      # dist/ 로 빌드
```

빌드 전 점검:

```bash
npx tsc -b                          # 타입 검사
npx tsx scripts/check-answers.ts    # 모든 프로젝트의 정답 구성이 시뮬레이션을 통과하는지 확인
```

`main` 브랜치에 push하면 GitHub Actions가 정답 점검과 빌드를 거쳐 자동 배포합니다. 점검에 실패하면 배포되지 않습니다.

## 폴더 구조

```
src/
  data/          프로젝트(대화·퀴즈·구성도·시나리오), AWS 서비스, 캐릭터, 개념 노트, 보상, 사무실 가구·기념품
  components/    화면 (메인, 진행, 대화, 퀴즈, 설계실, 구성도, 학습, 사무실)
  engine.ts      구성도 해석, 시나리오 판정, 채점
  store.ts       기록 저장, 완료 집계, 승급, 골드, 백업
  update.ts      새 버전 확인
scripts/
  check-answers.ts   정답 자동 점검
  office-art.py      사무실 기념품 픽셀 아트 생성
  office-room.py     사무실 방·가구 아이소메트릭 그림 생성
```
